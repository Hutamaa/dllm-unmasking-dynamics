The [canonical report](../reports/phase8/PHASE8_REPORT.md) is generated by
[finalize_phase8.py](../src/dllm_unmasking/finalize_phase8.py), entirely offline.
No GPU inference, downloads, HPC access, Phase 9 implementation, history rewriting,
commits, or pushes were performed.

## Raw imports and integrity

Already-downloaded originals remain in `outputs/phase8/qwen/run/` and
`outputs/phase8/qwen_512/run/`. Byte-verified separate snapshots are under
`outputs/phase8/imported/qwen_256/` and `outputs/phase8/imported/qwen_512/`.
Operational `.run.lock` files are deliberately not copied. Conflicting imports
fail without overwriting existing files. All raw directories remain ignored by Git.

- Each Qwen journal has 60 distinct starts and 60 matching completions, no pending
  evaluation, no duplicate key, and the exact selected 60 question IDs/strata.
- Manifest/config hashes, model and tokenizer revisions, pin hash, tokenizer
  metadata, templates, prompts, seeds, EOS IDs and protocol settings match.
  The configs differ only in token cap and output directory.
- The original extractor recomputes every Qwen correctness/extraction field.
  Saved results, summaries, paired tables and latency tables were regenerated in
  temporary storage and checked numerically. Historical files were not rewritten.
- Original Phase 2, 5 and 6 journals independently confirm every per-question
  correctness and GPU/wall timing value for the four LLaDA frontier references.
- Qwen-256: 28/60, mean GPU prefill+decode 5.3244087117513015 seconds,
  32 length-limited. Qwen-512: 50/60, 6.234682678222657 seconds, none length-limited.
  LTR P4: 37/60, 2.572615 seconds rounded; LTR P1: 43/60, 10.250551 seconds rounded.
- Recorded inference-source bytes were located by SHA256 in the current checkout
  or local Git history. Original generation defaults are not assumed effective:
  the audited call explicitly overrides sampling and repetition penalties.
- All 60 shorter outputs are exact token prefixes of the longer outputs.
  Budget sensitivity yields 23 correctness recoveries and one regression.
- Hash inventories confirm preservation of 119 pre-existing protected files,
  including earlier-phase tracked files and both original Qwen artifact trees.
  The finalizer additionally checks unchanged original diffusion artifact trees
  and Phase 7 reports before returning.

reproduce historical bootstrap endpoints. Historical per-run tables remain

## Remaining limits and missing artifacts

No required HPC result artifact is missing, and the supplied aggregate results
agree with raw journals. Scheduler stdout/accounting is not included in these run
directories, limiting independent scheduler-level timing validation. Weights and
native tokenizer bytes are not bundled, and raw results are not a public archive.
These are disclosed reproducibility limits, not evidence of altered observations.
Cross-model dominance remains unvalidated because timing scopes differ. The small,
balanced question subset, exploratory analyses and absence of latency repetitions
limit generalization. Numerical correctness is not proof of faithful reasoning.
No blocker was found for publication of the report with these qualifications.
