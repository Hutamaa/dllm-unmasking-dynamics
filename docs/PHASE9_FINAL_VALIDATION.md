## Statistical interpretation

The primary table has both-correct 11, both-incorrect 21, regressions 17 and
recoveries 11. Concise minus original accuracy is −10 percentage points, paired
95% interval [−26.67, +6.67], exact two-sided McNemar p=0.34492845088243484.
This neither establishes equivalent accuracy nor a population-level decline.

Bootstrap settings are explicit: 10,000 within-stratum paired draws, PCG64 seed 42
reset per comparison, observed stratum counts, linear percentile endpoints.
Secondary comparisons with original-512/LLaDA have their own two-test Holm family;
three exploratory stratum tests have another family. No favorable interval or
p-value is selected after seeing disagreement between procedures.

The original numerical evaluator remains unchanged. A separately labeled posthoc
last-numerical-mention diagnostic gives 33/60 original versus 37/60 concise. It can
select intermediate values and is not a corrected score or recommended replacement
parser. Official scores stay 28/60 and 22/60. No faithful-reasoning claim follows.

```bash

```

checks and preserves existing human forms. Public outputs have compact derived
metrics and bounded evidence quotes; full paired outputs, review forms, keys and

recorded manifests for any reproduction. Raw data must be restored locally; no
network or weights are needed.
